# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability reporting](../../security/advisories/new)
for this repository, or contact the maintainers listed in
`CODEOWNERS` directly.

Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including a minimal OpenAPI spec if relevant
- Any known mitigations

You should expect an initial response within 5 business days.
